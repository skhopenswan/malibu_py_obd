# 2017款雪佛兰迈锐宝 1.5T OBD 实时监控与同步存盘系统

本目录包含为您定制的迈锐宝 1.5T (LFV) OBD 实时检测、数据可信度校验与日志自动保存程序。

程序特点：**极简启动，无需复杂菜单；一边实时刷屏监视，一边自动以毫秒级时间戳同步写入 CSV 日志文件；自带高容错断线自动重连机制（行驶中线缆松动无需手动操作电脑）**。

---

## 1. 目录结构

```
malibu_live_monitor/
├── real_time_monitor.py   # 主程序：实时终端仪表盘 + CSV 同步存盘 + 断线自动重连容错
├── verify_obd.py          # 可信度校验：针对非原厂 ELM327 检测读数响应率、物理范围与卡死假数据
├── test_connection.py     # 连通性测试：快速检测 OBD 线缆与车辆端口通信
├── self_test.py           # 离线自测：无需连车，验证数据解析、计算、断线重连及 CSV/事件日志导出
├── requirements.txt       # Python 依赖库
├── README.md              # 本说明与诊断判读手册
└── data_logs/             # 自动创建的日志文件夹（保存生成的 CSV 数据与断线日志）
```

## 2. 快速使用指南

### 第一步：环境准备（仅需执行一次）
请在终端中运行以下命令安装必需依赖库：
```bash
pip install -r requirements.txt
```

### 第二步：硬件与车辆连接
1. 将 OBD USB 线缆插入笔记本，另一端插在迈锐宝驾驶员脚踏板上方的 OBD 接口。
2. 打开车辆点火开关（按下 Start 键不踩刹车让仪表盘亮起，或直接启动发动机进入怠速）。
3. 确认 Windows 设备管理器中的 COM 端口号（默认为 `COM4`，若为其他端口如 `COM3`，请修改脚本顶部的 `PORT_NAME = "COM3"`）。

### 第三步：ELM327 读数可信度校验（强烈推荐在首次使用时运行）
由于使用的是第三方/非原厂 ELM327 适配器，请在停车通电状态下运行校验脚本：
```bash
python verify_obd.py
```
程序会自动采样 10 次，对每项 OBD 数据进行**响应率**、**物理范围**（如转速 0–8000、电压 8–18V、水温 -40~130°C 等）及**动态卡死假数据校验**，并导出报告至 `data_logs/obd_verification_*.txt`，帮助您确认哪些 PID 在您的 ELM327 上 100% 准确可信。

### 第四步：启动实时监控与同步存盘
运行主程序：
```bash
python real_time_monitor.py
```
- **实时显示**：终端会自动刷新包含转速、水温、增压、燃油修正、节气门、变速箱油温等核心数据的面板。
- **同步存盘**：程序自动在 `data_logs/` 下创建形如 `malibu_obd_log_20260808_153000.csv` 的文件并实时写入每组数据。
- **行驶自动容错/断线重连**：行驶中如果发生 OBD USB 线缆松动或车辆掉线，系统会自动捕获异常并进入后台高容错循环重连模式，屏幕清晰提示重试状态。**恢复连接后自动接着往同一 CSV 写入后续数据**，全程无需驾驶员触碰电脑，保障行车安全。重连事件会记录在 `data_logs/malibu_connection_events_*.log` 中。
- **安全退出**：测试完成后，按键盘 `Ctrl+C` 即可安全断开 OBD 并保存完整 CSV 日志。

## 3. 重点读取的数据项与 CSV 字段映射

对应 `test_case.md` 第 4 章要求的重点数据项：

| 序号 | 中文数据项 | OBD PID / 来源 | CSV 表头列名 | 故障排查意义 |
|---|---|---|---|---|
| 1 | 发动机转速 | `RPM` | `RPM(rpm)` | 怠速平稳度、转速点对照（600/1500/2000/2500） |
| 2 | 车速 | `SPEED` | `Speed(km/h)` | 区分静止空吹与道路负载工况 |
| 3 | 冷却液温度 | `COOLANT_TEMP` | `CoolantTemp(C)` | 判断是否热车（热车水温通常 85-95°C） |
| 4 | 进气温度 | `INTAKE_TEMP` | `IntakeTemp(C)` | 评估中冷效能与环境进气温度 |
| 5 | 进气歧管绝对压力 | `INTAKE_PRESSURE` | `MAP(kPa)` | 热车怠速时通常明显低于大气压（约 30-40 kPa） |
| 6 | 大气压力 | `BAROMETRIC_PRESSURE` | `BaroPressure(kPa)` | 环境基准大气压（海平面约 101.3 kPa） |
| 7 | **涡轮增压值** | 动态计算 `(MAP - BARO)/100` | `BoostPressure(bar)` | **正数表示增压介入，负数表示真空状态（怠速负数正常）** |
| 8 | 节气门开度 | `THROTTLE_POS` | `ThrottlePos(%)` | 相对开度；怠速偏大（>15-20%）常提示积碳或补气 |
| 9 | **短期燃油修正** | `SHORT_FUEL_TRIM_1` | `STFT(%)` | **核心**：实时喷油补偿；偏正（>+10%）提示偏稀/漏气 |
| 10 | **长期燃油修正** | `LONG_FUEL_TRIM_1` | `LTFT(%)` | **核心**：长期系统偏差；持续 >+10% 提示系统性漏气/PCV |
| 11 | 空气流量 | `MAF` | `MAF(g/s)` | 进气计量数值（如支持） |
| 12 | 前氧传感器电压 | `O2_B1S1` | `O2_B1S1(V)` | 在 0.1V ~ 0.9V 快速跳变表示闭环正常 |
| 13 | 后氧传感器电压 | `O2_B1S2` | `O2_B1S2(V)` | 三元催化后段状态，通常在 0.6V-0.8V 相对稳定 |
| 14 | 点火提前角 | `TIMING_ADVANCE` | `TimingAdvance(deg)` | 发动机点火时序与爆震修正 |
| 15 | 系统/电瓶电压 | `ELM_VOLTAGE` | `Voltage(V)` | 发动机运转时正常应在 13.5V ~ 14.2V |
| 16 | 发动机负荷 | `ENGINE_LOAD` | `EngineLoad(%)` | 计算负荷率 |
| 17 | 燃油闭/开环状态 | `FUEL_STATUS` | `FuelStatus` | 显示 Closed loop（闭环）或 Open loop |
| 18 | 环境温度 | `AMB_AIR_TEMP` | `AmbAirTemp(C)` | 外部环境参照 |
| 19 | **变速箱油温** | 通用 GM Mode 22 `221940` | `TFT(C)` | 6AT(6T45) 变速箱油温，正常 70-95°C |

## 4. 故障判读逻辑（针对迈锐宝进气漏气/PCV/增压排查）

参照 `test_case.md` 第 5、6、7 章判读标准：

### 4.1 燃油修正（STFT / LTFT）判读
- **±5% 以内**：正常燃烧健康状态。
- **+5% ~ +10%**：轻微偏稀，需关注。
- **> +10% 且怠速最明显，空踩油门升转后下降**：**典型的进气歧管/PCV/真空管路漏气特征**（低负荷真空拉吸漏气最重，升转后漏气比例相对变小）。
- **全工况持续高正值**：考虑供油不足、MAF 计量偏差或氧传感器问题。

### 4.2 MAP / Boost 与节气门开度
- 热车怠速 MAP 高于 45-50 kPa，且节气门开度偏大，但转速不高：常伴随进气管道漏气或积碳严重。
- 加速时 Boost 无法升至 0.3 ~ 0.8 bar 以上，且伴随嘶嘶漏气声：重点排查增压软管、卡箍、中冷器接口。

## 5. 离线逻辑与断线重连自测验证

为确保程序逻辑无误，可在没有连接车辆时直接运行离线自测脚本：
```bash
python self_test.py
```
该自测脚本会模拟发动机各项工况数据，并在中途模拟一次掉线重连过程，检验数据格式化、Boost 计算、断线恢复及 CSV/事件日志落盘写入，结果显示 `🎉 离线断线重连与数据存盘逻辑自测全部通过！` 即可放心使用。
